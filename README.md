# hse-web-course
Репозиторий для заданий по курсу

## Описание проекта
**FabVocab — личный тренажёр лексики**

[Ссылка на макеты в Figma](https://www.figma.com/design/xUN4Z0TrwBmUEjMqxrIpU0/FabVocab?node-id=0-1)

Веб-приложение для сохранения и запоминания новых слов иностранного языка. Твоя личная система: каждое слово получает один из 8 цветов — собственную цветовую ассоциацию, которая работает как мнемоника и подсказка одновременно. Слова тренируются в квизе: правильных ответов подряд становится 5 — слово «выучено», ошибка — и оно снова «изучается». Забытые слова не наказываются, а мягко возвращаются через бейдж «пыль собирается». Приложение двуязычное (EN/RU), дружелюбное по тону, адаптировано под mobile и desktop.

**Страницы:**

**1. Home** — точка входа: статистика словаря по статусам, «слово дня», запуск тренировки или добавление слова.

**2. Dictionary** — все слова с поиском и фильтрами по цвету, части речи и статусу; вход в карточку слова.

**3. Add word** — быстрая запись слова: обязательные слово, часть речи, определение и цвет; перевод, пример и своё предложение можно добавить позже.

**4. Word detail** — карточка слова: все поля с редактированием, статус, прогресс закрепления и история практики.

**5. Training** — квиз в трёх состояниях: настройка сессии (направление «слово → определение» или наоборот, обычный режим с вариантами разных цветов или Hard — все четыре варианта одного цвета, длина 5/10/15), сам квиз с бесплатной подсказкой цвета и мгновенным фидбеком, экран результатов.

**6. Progress** — статистика ради ощущения движения: распределение слов по цветам и статусам, динамика по месяцам, свежие победы.
